## Дүгнэлт

Энэ session-ээр ном нэмэх, хайх, устгах, тоолуур болон API-ийн алдаа боловсруулах зан төлөвийг судалсан.
Оролтын баталгаажуулалтыг судалсан Couch Potato болон Antisocial арга барилууд хэд хэдэн зөрүү илрүүлэхэд үр дүнтэй байсан.
Couch Potato аяллаар шаардлагатай талбар дутуу байхад ном нэмэгдэж байгааг ажигласан.
Antisocial арга барилаар хүчингүй оны утгууд болон хайлтын том, жижиг үсгийн ялгааг шалгасан.
Fed-Ex арга барилаар номыг давтан нэмэх болон жагсаалтын өөрчлөлтийг мөшгөж, давхардал ба тоолуурын зөрүүг тэмдэглэсэн.
Supermodel аяллаар устгах товчны өнгө, хүснэгтийн харагдах байдал, үйлдлийн мессежийг ажигласан.
Saboteur аяллаар бүрэн бус JSON хүсэлтэд HTTP 400-ийн оронд HTTP 200 болон OK буцаж байгааг тогтоосон.
Charter-д дурдсан чиглэлүүдээс гадуурх тусдаа санамсаргүй олдвор энэ тайланд бүртгээгүй.
Дараагийн session-д өөр браузер, дэлгэцийн хэмжээ болон удаан хугацааны ажиллагааг судлах charter төлөвлөж болно.
Лаб 1-ийн Playwright тестэд тохирох оролт, assertion байсан тохиолдолд validation, давхардал, хайлт, тоолуурын зөрүүг барих боломжтой бөгөөд өнгө, layout-ийн асуудлыг хүний харааны үнэлгээтэй хослуулан CSS болон visual шалгалтаар автоматжуулж болно.
