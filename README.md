- 1000–2100 хоорондох бүхэл тоо байх шаардлагыг зөрчсөн
  999, 2101, 1999.5, 0, -1 онтой номууд нэмэгдсэн.
- 1000 болон 2100 он зөвшөөрөгдсөн нь зөв үр дүн байсан.
- Ижил гарчиг, зохиолч, онтой ном хоёр мөрөөр нэмэгдсэн.
- Alpha болон Beta хайлт ном олсон;
  alpha, ALPHA болон beta хайлт олоогүй.
- Хайлтыг цэвэрлэхэд бүрэн жагсаалт сэргэсэн.
- Тоолуур анхны, нэмсэн, устгасан болон хоосон төлөвт
  бодит номын тооноос нэгээр их байсан.
- Ном нэмэхэд «Ном нэмэгдлээ» мессеж харагдсан.
  Устгах үйлдлийн дараа мөн ижил буруу мессеж харагдсан.
- Олон үгтэй урт гарчиг мөр шилжин хэвийн харагдсан.
  Зайгүй урт гарчиг хүснэгтийг дэлгэцээс халуулсан.
- Бүрэн бус JSON хүсэлтэд HTTP 200 OK,
  {"result":"OK"} буцсан.
