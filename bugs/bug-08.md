# BUG-08 — Ном устгахад «Ном нэмэгдлээ» гэсэн мессеж гардаг

- Тестер: С. Чингэрэл
- Огноо: 2026-10-24
- Ажигласан цаг: 23:16, 23:30 (+08:00)
- Хаяг: http://localhost:3000
- Severity: Minor
- Төлөв: Илэрсэн

## Урьдчилсан нөхцөл

Жагсаалтад устгах боломжтой ном байна.
Нэмэх үйлдлийн өмнөх мессежийг refresh хийж арилгасан.

## Давтах алхам

1. Testing Book / Testing Writer / 2000 номыг нэмнэ.
2. Хуудсыг refresh хийж мессежийг арилгана.
3. Testing Book номын «Устгах» товч дарна.
4. Номын мөр болон гарсан мессежийг шалгана.

## Хүлээгдэх үр дүн

Ном устсан бол устгах үйлдэлд тохирсон
«Ном устгагдлаа» зэрэг мессеж харуулна.

## Бодит үр дүн

Номын мөр устсан боловч
«Ном нэмэгдлээ» гэсэн мессеж харагдсан.

23:16-д мөрийн тоо 6-аас 5, тоолуур 7-оос 6 болсон.
Бүх номыг устгасан төлөвт мөн «Ном нэмэгдлээ» харагдсан.

## Нөлөө

Хэрэглэгч устгах үйлдлийн үр дүнг
нэмэх үйлдэлтэй андуурах боломжтой.
