# BUG-04 — Ижил гарчиг, зохиолчтой ном давхар нэмэгддэг

- Тестер: С. Чингэрэл
- Огноо: 2026-10-24
- Ажигласан цаг: 23:04 (+08:00)
- Хаяг: http://localhost:3000
- Severity: Major
- Төлөв: Давхардсан бүртгэл ажиглагдсан

## Урьдчилсан нөхцөл

Серверийг дахин асаасан.
Анхны 3 номтой жагсаалт нээлттэй байна.

## Давтах алхам

1. Дараах номыг нэмнэ:
   - Гарчиг: Exploratory Test Book
   - Зохиолч: Session Author
   - Он: 2000
2. Ном хүснэгтэд орсныг шалгана.
3. Яг ижил гарчиг, зохиолч, онтой номыг дахин нэмнэ.
4. Хүснэгтийг ажиглана.

## Хүлээгдэх үр дүн

Ижил гарчиг, зохиолчтой номын давхардлыг хориглох
шаардлагын дагуу хоёр дахь бүртгэлийг нэмэхгүй,
давхардлын тухай мэдээлнэ.

## Бодит үр дүн

Exploratory Test Book / Session Author / 2000 ном
хүснэгтэд хоёр тусдаа мөрөөр нэмэгдсэн.
«Ном нэмэгдлээ» мессеж харагдсан.

## Нөлөө

Ижил номын давхардсан бүртгэл үүснэ.
